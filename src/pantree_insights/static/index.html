Ask a question to see the agents work

Each question goes through a team of agents:

  1. Understanding works out exactly what you mean, asks until nothing is unclear, then shows you what it will compute to confirm
  2. Planner turns it into an analysis plan
  3. SQL writer writes the query with the shop's metric definitions and verified reference queries
  4. Safety checks allow only read-only, summarised queries on the right joins
  5. Number check recomputes the metric from its definition and compares
  6. Validator checks the query answers what you asked
  7. Analyst explains the result; every number is checked
